업로드 임시 파일 정리

목표

업로드가 끝나거나 실패한 뒤 tmp/uploads/에 남는 조각 파일을 정한 기간 안에 지운다. 지금은 평균 41GB가 쌓이고 운영자가 매주 손으로 지운다(운영 기록 2026-11-04).

범위 밖

  • 원본 저장소(S3)의 수명 주기 정책
  • 이어 올리기(resumable upload)

요구사항

R1 완료된 업로드

R1.1업로드가 완료되면 그 업로드의 조각 파일을 10분 안에 지운다.
R1.2지운 파일 수와 크기를 upload_cleanup 지표로 남긴다.

R2 실패하거나 멈춘 업로드

R2.1업로드가 실패 상태가 되면 조각 파일을 1시간 안에 지운다.
R2.2진행 중인 업로드의 파일은 지우지 않는다.
R2.3마지막 쓰기에서 3일이 지난 멈춘 업로드는 실패로 바꾸고 조각 파일을 지운다.7일 → 3일 · 10:38 저장

수용 기준

SC-1WHEN 업로드가 완료 상태가 되면 THE SYSTEM SHALL 10분 안에 조각 파일을 지운다.
SC-2WHEN 마지막 쓰기 뒤 72시간이 지나면 THE SYSTEM SHALL 업로드를 실패로 바꾸고 조각 파일을 지운다.
