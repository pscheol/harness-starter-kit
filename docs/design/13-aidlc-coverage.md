# 13. AI-DLC 학습 가이드 대응표

- 단계: 구현 전 점검(전 단계). 기준일 2026-11-23.
- 기준 자료: [AI-DLC 학습 가이드](../AI-DLC_학습가이드.html)(2026-11-21 기준, 14장). 그림 안 데이터(33 스테이지 노선도, 프로필 11종 막대)도 기준에 넣는다. 스테이지 이름은 [핸드북 02](../ai-dlc/02-workflow.html)와 맞춘다.
- 비교 대상: 이 폴더의 [README](README.md) 공통 계약과 01~12 · 14, [harness-next 05](../harness-next/05-principles.html), v2가 그대로 쓰는 [킷 SDD 템플릿](../../plugins/kns/skills/bootstrap/templates/common/agents-docs/_spec-templates/)과 설계서가 정한 템플릿 변경(T-des §4.5 · §13).
- 보완 반영: 2026-11-23. 판정은 반영 뒤 값이다. 바뀐 곳은 §7.

## 1. 기준과 방법

가이드가 가르치는 개념을 하나씩 행으로 나누고, 설계서에서 그 개념을 다루는 자리를 찾아 판정한다. 개념 표(A)는 정의·원칙·단계·단위·의식·산출물·게이트·맥락·경로·측정·브라운필드·도구를 다루고, 스테이지 표(B)는 v2의 33 스테이지를 하나씩 본다.

harness-next에 계획만 있고 설계서에 형식·명령·완료 기준이 없으면 설계 기준으로는 없는 것으로 판정한다(예: 14가 생기기 전 HN03 P24의 배포·운영 기록).

위치 표기:

| 표기 | 가리키는 곳 |
|---|---|
| `08 §3.4` · `08 DS-R5` | 이 폴더 `08-design-stage.md`의 3.4절 · 요구사항 ID |
| `README §3` | 이 폴더 README 공통 계약의 3절 |
| `HN03 P24` · `HN04 <절>` · `HN05 <절>` | harness-next 03(계획) · 04(활용) · 05(원칙) 문서의 단계·절 제목 |
| `T-req §7` · `T-des §14` · `T-tasks <제목>` | 킷 SDD 템플릿 requirements · design · tasks의 제목 번호 |
| `가이드 5장` | 학습 가이드의 장 번호 |

판정:

| 판정 | 뜻 |
|---|---|
| 충족 | 설계서에 형식·명령·검사 중 하나 이상이 있고, 가이드가 말하는 효과가 난다 |
| 부분 | 일부만 있다. 빠진 부분을 보완 열에 적는다 |
| 누락 | 설계서에 없다 |
| 의도적 제외 | 설계서가 이유를 대고 다르게 정했거나, 킷이 만들 대상이 아니다 |

보완의 우선순위:

- 필수: README §1 원칙 6이 약속한 다섯 원칙(세 단계, 대화 방향 역전, Unit·Bolt, 단계별 승인 게이트, 문서로 남는 맥락)과 가이드 3장 원칙 중 "선택 사항으로 두지 않는다"고 한 것이 이것 없이는 성립하지 않는다.
- 권장: 없어도 위 원칙은 지켜지지만, 가이드가 실패 원인이나 도입 조건으로 꼽은 것이다.
