# /self-review

## 절차

1. **변경 확인** — `git diff`와 `git status`로 이번 변경 전체를 다시 읽는다.
2. **체크리스트** — `.agents/docs/QUALITY_SCORE.md`를 항목별로 확인한다.
3. **범위 검사** — 요청 범위를 넘거나 좁힌 부분이 있는가.
4. **재사용 검사** — 기존 owner를 두고 새로 만든 것이 있는가.
5. **위험 영역** — `AGENTS.md`의 Project Invariants 표에 걸리는 변경인가.
6. **검증** — 필요한 게이트를 실행한다.
7. **보고** — 발견 사항을 심각도 순으로. 자동화가 잡는 항목은 제외한다.

## 금지

- 포맷·린트·타입 등 자동화 위임 영역 지적
- 변경되지 않은 코드의 스타일 지적
- 발견 사항을 조용히 자동 수정 — 보고 후 사용자 판단
