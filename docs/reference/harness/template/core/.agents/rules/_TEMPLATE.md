## 작성 지침

- **자동화가 잡을 수 있는 것은 규칙으로 쓰지 않는다.** 훅이나 게이트에 넣는다.
- **"왜"를 반드시 적는다.** 이유 없는 규칙은 지켜지지 않고, 지켜지지 않는 규칙은 나머지 규칙의 신뢰도를 깎는다.
- **안티-규칙을 적는다.** 무엇을 지적하면 안 되는지가, 무엇을 지적해야 하는지만큼 중요하다.
- 한 파일 = 한 주제. 여러 주제를 묶으면 부분 로드가 불가능해진다.
