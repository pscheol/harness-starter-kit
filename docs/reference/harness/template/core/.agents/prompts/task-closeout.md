# 작업 마무리 프롬프트

```text
지금 작업을 검토로 넘길 준비를 해줘.

1. 자체 검토
   - .agents/docs/QUALITY_SCORE.md 체크리스트를 항목별로 확인한다.
   - 변경 diff 를 다시 읽고, 요청 범위를 넘거나 좁힌 부분이 없는지 본다.
   - 자동화가 잡는 항목(포맷/린트/타입)은 검토하지 않는다.

2. 기록 갱신
   - tasks.md 체크박스를 갱신한다.
   - 설계와 구현이 어긋났으면 design.md 를 먼저 고친다.
   - 새 부채가 생겼으면 exec-plans/tech-debt-tracker.md 에 적는다.
   - 코드 변경과 문서 갱신을 같은 커밋에 넣는다.

3. 게이트
   - 필수 게이트를 실행한다.
   - 위험 변경이면 통합 게이트까지 실행한다.

4. 최종 보고 (3줄 + 상세)
   - 무엇을 / 왜 / 다음 단계
   - 검증 결과와 생략 항목
   - 사람이 확인해야 할 항목
```
