# .agents/prompts — 재사용 프롬프트

여러 세션·여러 도구에서 반복해서 쓰는 지시문을 둔다. 사람이 복사해 붙이거나, 슬래시 커맨드가 참조한다.

| 프롬프트                                 | 용도                                        |
| ---------------------------------------- | ------------------------------------------- |
| [`task-run.md`](./task-run.md)           | 작업 하나를 착수부터 검증까지 진행          |
| [`task-closeout.md`](./task-closeout.md) | 작업을 검토로 넘기기 전 마무리              |
| [`onboarding.md`](./onboarding.md)       | 새 저장소/새 작업자의 하네스 준비 상태 확인 |

## 작성 규칙

- 프롬프트는 **정책을 복제하지 않는다.** `.agents/rules/`를 참조만 한다.
- 매번 사람이 채워야 하는 값은 `<...>` 자리표시자로 남긴다.
- 프롬프트가 길어지면 규칙이 부족하다는 신호다. 규칙으로 옮긴다.
