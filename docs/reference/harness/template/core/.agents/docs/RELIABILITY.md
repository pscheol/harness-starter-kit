## 기본 기준

- **정리 의무**: 열었으면 닫는다. 구독·타이머·스트림·핸들은 수명주기와 짝을 맞춘다.
- **취소 가능성**: 오래 걸리는 작업은 취소 경로를 갖는다.
- **타임아웃**: 외부 호출에는 타임아웃이 있다. 무한 대기는 장애다.
- **재시도**: 재시도는 멱등한 작업에만. 백오프를 둔다.
- **부분 실패**: 일부 실패가 전체를 망가뜨리지 않게 한다. 사용자에게 무엇이 실패했는지 알린다.
- **중복 입력**: 중복 클릭·중복 요청이 상태를 깨지 않는다.
