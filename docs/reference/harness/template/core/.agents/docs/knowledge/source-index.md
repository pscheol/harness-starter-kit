# Source Index

에이전트가 반복 참조하는 **외부 근거의 색인**이다. 각 근거에 안정적인 ID를 부여해, 문서와 이슈에서 경로 대신 ID로 인용한다.

## 왜 ID 인가

경로와 URL은 바뀐다. ID로 인용하면 자료가 이동해도 인용이 깨지지 않고, 이 표 한 줄만 고치면 된다.

## 색인

| Source ID      | 종류          | 위치 | 최종 확인 | 비고                                            |
| -------------- | ------------- | ---- | --------- | ----------------------------------------------- |
| DOC-API-001    | API 명세      | TBD  |           | **등록 전에는 API 영향 작업을 시작하지 않는다** |
| DOC-UX-001     | UX 가이드     | TBD  |           |                                                 |
| DOC-MANUAL-001 | 사용자 매뉴얼 | TBD  |           |                                                 |

## 규칙

- 위치가 `TBD`인 근거가 필요한 작업은 **구현하지 않는다.** 필요한 문서 위치를 먼저 요청한다.
- 외부 문서를 반복 참조하면 요약을 `.agents/docs/references/`에 캐시하고 여기에 등록한다.
- 원본 대용량 자산은 저장소에 넣지 않는다. 위치와 접근 방법만 적는다.
