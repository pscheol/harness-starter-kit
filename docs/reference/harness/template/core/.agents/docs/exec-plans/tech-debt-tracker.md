## 기록 기준

- 지금 고치지 않기로 **결정**한 것만 적는다. 아이디어 목록이 아니다.
- 각 항목에는 **재발 감지 방법**을 적는다. 감지되지 않는 부채는 관리되지 않는다.
- `.agents/rules/pr-review-policy.md`의 negative knowledge 표와 연동한다. 여기 있는 항목은 리뷰에서 반복 지적하지 않는다.
