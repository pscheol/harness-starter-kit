# references — 외부 문서 캐시·요약

에이전트가 반복 참조해야 하는 외부 자료의 **요약 또는 캐시**를 둔다.

## 규칙

- 원본 대용량 파일을 그대로 커밋하지 않는다. 필요한 부분만 요약한다.
- 각 항목은 `../knowledge/source-index.md`에 Source ID로 등록한다.
- 요약에는 **원본 버전/날짜**를 적는다. 원본이 갱신되면 요약도 stale 이다.
- 라이브러리 API는 기억이 아니라 공식 문서에서 확인한 뒤 요약한다.

## 구조 예시

```text
references/
├── README.md
├── originals/          # 원본이 꼭 필요한 경우만 (크기 주의)
└── <topic>.md          # 요약
```
