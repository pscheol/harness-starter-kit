# design-docs — 설계 원칙과 운영 의사결정

**반복 적용되는 방법론**과 **운영 의사결정**을 둔다.

개별 티켓·기능의 설계는 여기가 아니라 `.agents/docs/product-specs/<작업단위>/design.md`에 둔다.

## 여기에 두는 것

- 여러 작업에 반복 적용되는 개발 방법론
- 아키텍처 결정 기록(ADR)
- 하네스 운영 회고
- 팀이 합의한 트레이드오프

## 여기에 두지 않는 것

- 개별 티켓 폴더 (`design-docs/<ticket>/` 금지)
- 재생성 가능한 문서 (`generated/`로)
- 외부 문서 사본 (`references/`로)
