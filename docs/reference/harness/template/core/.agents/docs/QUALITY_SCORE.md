# Quality Score — {{PROJECT_NAME}}

작업을 넘기기 전 스스로 확인하는 기준이다. 점수를 매기는 게 목적이 아니라 **빠뜨린 것을 찾는 것**이 목적이다.

## 체크리스트

### 정확성

- [ ] 요구사항의 모든 항목을 다뤘다 (일부만 하고 완료로 보고하지 않았다)
- [ ] 경계값과 실패 경로를 처리했다
- [ ] 추측으로 작성한 API 사용이 없다

### 범위

- [ ] 요청 범위를 넘지 않았다
- [ ] 요청 범위를 좁히지 않았다
- [ ] 무관한 리팩터링을 섞지 않았다

### 재사용

- [ ] 기존 owner를 검색했고 재사용/확장을 먼저 검토했다
- [ ] 사용처 없는 추상화를 만들지 않았다

### 검증

- [ ] 대상 테스트를 돌렸다
- [ ] 필수 게이트를 돌렸다
- [ ] 생략한 검증과 그 이유를 기록했다

### 기록

- [ ] SDD 산출물을 갱신했다 (또는 예외 사유를 남겼다)
- [ ] 잔여 위험과 사람 확인 항목을 적었다

### 정직성

- [ ] 실패한 것을 실패했다고 적었다
- [ ] 확인하지 않은 것을 확인했다고 적지 않았다
