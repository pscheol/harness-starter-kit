# optional / design-system

UI 작업에서 **디자인 소스를 단일 진실로 강제**하는 모듈이다.

## 언제 설치하는가

- 디자인 도구(Figma 등)에 기준 문서가 있다
- 에이전트가 임의로 색·간격·폰트 스케일을 만들어내는 문제가 있다
- UI 회귀가 반복된다

백엔드 전용 저장소나 디자인 기준 문서가 없는 프로젝트에는 설치하지 않는다.

## 설치되는 것

```text
.agents/rules/design-system.md
```

## 설치 후 반드시 채울 것

- 디자인 소스 URL과 **어느 노드/페이지가 최신 기준인지**
- 토큰이 코드에서 어디에 정의되어 있는지 (owner 파일)
- 기준이 충돌할 때의 우선순위

기준 문서 링크만 있고 "어느 것이 최신인가"가 없으면, 에이전트는 오래된 화면을 근거로 삼는다.
