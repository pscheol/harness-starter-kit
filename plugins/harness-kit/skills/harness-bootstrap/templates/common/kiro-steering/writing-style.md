# 문체 (포인터)

원본: `.agents/rules/writing-style.md` — 스펙 문서·주석·커밋 메시지·리포트에 모두 적용된다.

요약:

- 작업 일지를 쓰지 않는다 — `대조 결과`, `~임을 확인했다`, `검토해 본 결과` 금지. 결과와 사실만 남긴다.
- 지워도 뜻이 안 바뀌는 문장은 쓰지 않는다 — `계약이 된다`, `안정적으로 처리한다`, `성공적으로 완료되었습니다`.
- 능동으로 짧게. 한 문장에 주장 하나, 한 문단 3줄 이내.
- 판단은 숫자·조건으로. `빠르다` 대신 `p95 120ms`. 모르면 `[NEEDS CLARIFICATION: 질문]`.
- 문서 본문에 이모지를 넣지 않고, 굵게는 한 화면에 두세 번까지.
