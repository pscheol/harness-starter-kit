# 전역 설계 결정 색인 (Decisions / ADR)

`decisions/`는 **제품·기능을 가로지르는 전역 결정**을 담는다. 특정 기능의 설계는 여기가 아니라
해당 제품 폴더의 `product-*-specs/design/<feature>.md` 에 둔다.

담는 것:
1. **핵심 신념** `core-beliefs.md` — 에이전트 우선 운영의 전역 원칙(항상 로드 가치).
2. **개별 ADR** `<slug>.md` — 아키텍처/기술 선택의 기록. 템플릿: `_template.md`.

| 문서 | 내용 | 상태 |
|---|---|---|
| `core-beliefs.md` | 에이전트 우선 운영 핵심 신념 | 채택 |
| `<slug>.md` | (예시) 결정 한 줄 요약 | 제안 |

> 상태 값: `제안` / `채택` / `폐기`.

## 작성 규칙

- 새 전역 결정은 `_template.md`로 ADR을 만들고 이 색인에 등록한다(**미등록 = "존재하지 않는 것"**).
- 결정의 근거(why)와 기각한 대안을 남긴다.
- 폐기된 결정은 **삭제하지 말고** 상태를 `폐기`로 바꾸고 대체 문서를 링크한다(이력 보존).
- 규칙(항상 지켜야 하는 규범)은 결정이 아니라 `.agents/rules/`의 정본으로 승격한다.
