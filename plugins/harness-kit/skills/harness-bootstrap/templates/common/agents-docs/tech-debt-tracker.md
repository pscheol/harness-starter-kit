# 기술 부채 추적기

기술 부채는 **고금리 대출**이다. 누적 전에 조금씩 갚는다.
발견 즉시 여기에 등록하고, 해결 시 PR 링크와 함께 닫는다.

| ID | 항목 | 위치 | 심각도 | 상태 | 비고 |
|---|---|---|---|---|---|
| TD-000 | (예시) 초기 스캐폴딩 미비 | - | low | open | 하네스 구축 단계 |

심각도: low / medium / high. 상태: open / in-progress / mitigated / closed.

> 작성 규칙
> - **발견 즉시 등록**한다(미등록 부채 = 보이지 않는 이자).
> - 해결 시 상태를 `closed`로 바꾸고 **해소 근거 + PR/커밋 링크**를 비고에 남긴다.
> - 코드로 닫을 수 없는 운영성 부채는 `mitigated`(완화)로 두고 잔여 책임을 명시한다.
> - 항목은 삭제하지 않는다(이력 보존). 심각도·상태만 갱신한다.
