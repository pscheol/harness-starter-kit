# UI 상태 — 종류를 먼저 정하고, 파생은 저장하지 않는다

상태를 어디에 둘지는 취향이 아니라 **종류가 결정한다.** 종류를 섞으면 동기화 코드가 생기고,
동기화 코드는 반드시 어긋난다. 어긋난 뒤에는 "새로고침하면 됩니다"가 기능 설명이 된다.

## 1. 네 가지 상태

| 종류 | 무엇 | 사는 곳 | 진실의 원천 |
|---|---|---|---|
| 서버 상태 | 서버가 소유. 언제든 낡는다 | 서버 캐시 계층(쿼리 라이브러리) | 서버 |
| 클라이언트 상태 | 이 세션에만 있는 것(모달 열림·선택·토글) | 컴포넌트 지역 → 필요할 때만 스토어 | 클라이언트 |
| URL 상태 | 공유·새로고침·뒤로가기가 살아야 하는 것 | 경로·쿼리스트링 | URL |
| 폼 상태 | 편집 중인 초안 | 폼 라이브러리 | 제출 전까지는 폼 |

- **서버 상태를 클라이언트 스토어로 복사하지 않는다.** 복사하는 순간 무효화 책임이 생기고,
  그 책임은 어느 화면에선가 빠진다. 서버 상태는 캐시 계층이 소유한다.
- 지역 상태로 되는 것을 전역에 올리지 않는다. 전역은 승격이지 기본값이 아니다.
- 승격 근거는 하나다 — **여러 화면이 동시에 읽고 쓴다.** prop 을 두세 단계 넘기는 건 근거가 아니다.

## 2. URL 에 두는 것

필터 · 정렬 · 페이지 · 활성 탭 · 검색어 · 상세 대상 ID.

판단 기준은 하나다 — **그 링크를 붙여넣었을 때 같은 화면이 나와야 하는가.** 그렇다면 URL 상태다.
데스크톱(Electron)도 같다. 창을 복원했을 때 같은 화면이 나와야 하는 값은 라우터가 소유한다.

## 3. 파생 상태는 저장하지 않는다

- 합계 · 필터 결과 · 유효성 · "버튼 활성화 여부"는 **계산한다.** 상태로 두면 원본과 어긋난다.
- 메모이제이션은 **측정된 비용이 있을 때만** 넣는다(`frontend-performance.md`).
- 예외는 하나 — 계산이 비싸고 입력이 안정적일 때. 그때는 왜 저장하는지 주석으로 남긴다
  (`code-comments.md`).

## 4. 네 가지 화면 상태

데이터를 쓰는 화면은 네 가지를 모두 갖는다. 무엇을 안 만들었는지 스스로 말할 수 있어야 한다.

| 상태 | 빠뜨리면 생기는 일 |
|---|---|
| loading | 첫 페인트에 레이아웃이 튄다 |
| empty | "0건"이 에러처럼 보인다 |
| error | 사용자에게 다음 행동이 없다 |
| partial | 위젯 하나가 실패했는데 화면 전체가 죽는다 |

- 에러 화면은 **다음 행동**을 준다: 재시도 · 뒤로 · 문의. 원인 문자열만 뿌리지 않는다.
- 스켈레톤은 최종 레이아웃과 크기가 같아야 한다. 다르면 로딩이 끝날 때 화면이 튄다.
- 부분 실패는 부분만 실패로 표시한다. 화면 하나에 에러 경계를 하나만 두면 partial 이 사라진다.

## 5. 낙관적 업데이트

쓰면 순서를 지킨다: **스냅샷 → 즉시 반영 → 실패 시 스냅샷 복구 → 사용자에게 보이는 실패 통지.**

- 롤백 없는 낙관적 업데이트는 조용한 데이터 불일치다. 롤백을 못 쓰겠으면 낙관적 업데이트를 쓰지 않는다.
- 실패를 토스트 하나로 끝내고 화면은 성공한 것처럼 두지 않는다.
- 연속 편집은 마지막 요청이 마지막에 도착한다는 보장이 없다. 순서가 중요하면 큐를 두거나
  서버 응답으로 확정한다.

## 6. 자동화로 잡히는 영역

여기 적힌 것은 도구가 잡는다. **리뷰에서 다시 지적하지 않는다**(`pr-review-policy.md`).

- [ ] 훅 의존성 배열 누락 — 린터 규칙
- [ ] 미사용 상태·미사용 셀렉터 — dead code 도구
- [ ] 서버 응답을 `as` 로 단정 — 타입 검사 + 경계 파싱 규칙(`guardrails.md`)

## 7. 안티-규칙

- ❌ "나중에 필요할 것 같아서" 전역 스토어에 먼저 올리는 것.
- ❌ 로딩 상태를 컴포넌트마다 손수 만드는 것 — 서버 상태 계층이 이미 준다.
- ❌ URL 에 둘 값을 스토어에 두고 링크 공유 기능을 따로 만드는 것.
- ❌ 이 규칙을 근거로 상태 관리 전면 교체를 시작하는 것. 별건은 `tech-debt-tracker.md`.
