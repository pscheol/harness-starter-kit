# 접근성 — 기준선은 협상 대상이 아니다

이 프로젝트의 기준선은 **WCAG 2.2 AA** 다. 새로 만드는 화면과 컴포넌트는 이 기준을 만족한 상태로
머지한다. "나중에 접근성 작업"으로 미루면 그 작업은 오지 않는다.

## 1. 시맨틱이 먼저다

역할에 맞는 요소를 쓴다. 범용 컨테이너에 클릭 핸들러를 붙여 버튼을 흉내 내지 않는다.

```text
✗ 클릭 핸들러를 붙인 컨테이너 + role="button" + tabindex + 키 핸들러
✓ button 요소 하나
```

흉내 낸 컨트롤은 포커스·키보드·상태 전달·확대 축소를 전부 직접 구현해야 하고, 대개 하나 이상 빠진다.
ARIA 는 **시맨틱으로 표현할 수 없을 때만** 쓴다. 첫 번째 ARIA 규칙은 "ARIA 를 쓰지 않는 것"이다.

## 2. 키보드

- 모든 조작은 키보드만으로 도달·수행·취소할 수 있어야 한다.
- 포커스 순서는 시각 순서와 같다. `tabindex` 에 양수를 쓰지 않는다.
- **포커스 표시를 지우지 않는다.** 마음에 안 들면 다시 그리되 없애지 않는다.
- 모달·드로어는 열릴 때 포커스를 안으로 옮기고, 닫힐 때 **열었던 곳으로 되돌린다.**
  열려 있는 동안 포커스가 바깥으로 새지 않는다.
- `Esc` 로 닫히는 것이 기본이다. 닫히면 안 되는 경우가 예외이고, 그건 근거가 필요하다.

## 3. 이름·역할·상태

모든 인터랙티브 요소는 **접근 가능한 이름**을 갖는다. 아이콘만 있는 버튼이 가장 자주 빠진다.

- 이미지: 정보를 담으면 대체 텍스트, 장식이면 빈 대체 텍스트. "이미지"라고 쓰지 않는다.
- 상태는 시각으로만 전달하지 않는다 — 선택·확장·정렬·오류는 대응하는 속성으로 함께 알린다.
- 동적으로 바뀌는 알림(저장됨·오류·검색 결과 수)은 라이브 영역으로 읽히게 한다.
  단, 모든 것을 라이브 영역으로 만들지 않는다. 시끄러우면 사용자가 꺼 버린다.

## 4. 색과 대비

- 본문 텍스트 4.5:1, 큰 텍스트·아이콘·경계선 3:1 이상.
- **색만으로 의미를 전달하지 않는다.** 오류는 빨강 + 문구, 필수는 색 + 표식.
- 다크 테마가 있으면 두 테마 모두에서 대비를 확인한다. 한쪽만 맞춘 팔레트가 흔하다.

## 5. 모션

- 사용자의 모션 감소 설정을 존중한다. 감소 설정에서는 이동·확대·시차 효과를 끄거나 페이드로 낮춘다.
- 자동 재생·반복 애니메이션은 5초를 넘기지 않거나 멈출 수단을 준다.
- 깜빡임은 초당 3회 미만.

## 6. 폼

- 모든 입력에 이름이 붙은 라벨. 플레이스홀더는 라벨이 아니다.
- 오류는 **입력과 프로그램적으로 연결**하고, 무엇이 잘못됐고 어떻게 고치는지 함께 쓴다.
- 오류 발생 시 포커스를 첫 오류로 옮긴다.
- 되돌릴 수 없는 제출은 확인 단계나 취소 수단을 둔다.

## 7. 검사 방법

자동 검사로는 위반의 일부만 잡힌다. 나머지는 사람이 본다(`verification-ladder.md` L4).

| 단계 | 무엇 |
|---|---|
| 자동 | 접근성 린터 + 런타임 검사기를 CI 에 넣는다(대비·이름 누락·중복 id 등) |
| 수동 최소 | Tab 만으로 주요 흐름 완주 · 확대 200% 에서 잘림 없음 · 모션 감소 설정 확인 |
| 수동 확장 | 스크린 리더로 새 컴포넌트 1회 통과 |

## 8. 자동화로 잡히는 영역

- [ ] 대체 텍스트 누락·라벨 없는 입력·중복 id — 접근성 린터
- [ ] 대비 비율 — 런타임 검사기
- [ ] 양수 `tabindex`·금지된 ARIA 조합 — 린터

**리뷰에서 이 항목을 다시 지적하지 않는다**(`pr-review-policy.md`).

## 9. 안티-규칙

- ❌ 자동 검사 통과를 접근성 완료로 선언하는 것. 자동 검사가 잡는 범위는 일부다.
- ❌ 모든 요소에 ARIA 속성을 붙이는 것. 잘못 붙인 ARIA 는 없는 것보다 나쁘다.
- ❌ 접근성을 이유로 시각 디자인 결정을 임의로 바꾸는 것 — 대비 미달은 보고하고 디자인 소스에서 고친다.
- ❌ Electron 이라서 접근성이 필요 없다고 판단하는 것. 데스크톱에도 키보드 사용자와 확대 사용자가 있다.
