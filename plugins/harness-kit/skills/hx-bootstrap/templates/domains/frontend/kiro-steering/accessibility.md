# 접근성 (포인터)

원본: `.agents/rules/accessibility.md` — 화면·컴포넌트를 만들거나 고치기 전에 연다.

요약:

- 기준은 WCAG 2.2 AA. 나중에 붙이는 비용이 처음부터 하는 비용보다 훨씬 크다.
- **시맨틱 요소가 먼저다.** `div` + 클릭 핸들러 대신 `button`·`a`·`label` 을 쓴다. ARIA 는 최후 수단.
- 마우스로 되는 것은 키보드로도 된다 — 포커스 순서·포커스 표시·함정 없는 모달.
- 이름·역할·상태를 준다. 아이콘 버튼에는 접근 가능한 이름이 필요하다.
- 대비 기준을 지킨다(본문 4.5:1 · 큰 글씨 3:1 · UI 경계 3:1). 색만으로 의미를 전달하지 않는다.
- `prefers-reduced-motion` 을 존중한다. 폼 오류는 어느 필드가 왜 틀렸는지 텍스트로 말한다.
- 자동 검사는 일부만 잡는다 — 키보드 통과와 스크린리더 확인은 사람이 한다.
