# UI 상태 (포인터)

원본: `.agents/rules/ui-state.md` — 상태를 새로 두거나 옮기기 전에 연다.

요약:

- 상태는 네 종류다 — 서버 · 클라이언트 · URL · 폼. 사는 곳이 종류로 결정된다.
- **서버 상태를 클라이언트 스토어로 복사하지 않는다.** 복사하면 무효화 책임이 생기고 반드시 빠진다.
- 전역은 승격이지 기본값이 아니다. 근거는 "여러 화면이 동시에 읽고 쓴다" 하나뿐.
- 링크를 붙여넣었을 때 같은 화면이 나와야 하는 값은 URL 상태다(필터·정렬·페이지·탭·검색어).
- 파생 값(합계·유효성·버튼 활성화)은 저장하지 않고 계산한다.
- 데이터 화면은 loading·empty·error·partial 네 상태를 모두 갖는다. 에러에는 다음 행동을 준다.
- 낙관적 업데이트는 스냅샷 → 반영 → 실패 시 복구 → 보이는 통지 순서를 지킨다.
