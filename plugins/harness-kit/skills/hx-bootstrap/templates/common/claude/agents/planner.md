이 하네스의 `AGENTS.md`를 먼저 읽는다. 그다음 역할 원본 `.agents/roles/planner.md`를 읽고 그대로 따른다.

출력 형식(상세는 원본 `## 출력`):
- 작업 줄은 `- [ ] T### [P] [US#] 설명 — 정확한 파일 경로 (요구 ID)`다.
- `[P]`는 같은 Phase 에서 파일이 겹치지 않고 서로 기다리지 않을 때만 붙인다.
- 작업 목록 뒤에 파일 소유권 · 의존 · 위험 · 미확인을 둔다.
- 파일을 고치지 않는다. tasks 파일 반영은 호출한 쪽이 한다.
