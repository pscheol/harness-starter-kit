# 리뷰 정책 (포인터)

원본: `.agents/rules/pr-review-policy.md` — 코드를 리뷰하거나 리뷰 지적을 받을 때 연다.

요약:

- 포매터·린터·타입 검사·구조 검사가 잡는 것은 **리뷰에서 언급하지 않는다**. 통과했다면 도구 설정을 고친다.
- 보는 순서: 정확성 → 안전성 → 계약 → 경계 → 재사용 → 검증 → 읽힘.
- 지적은 위치·무엇이·왜(근거 규칙)·어떻게 네 조각을 갖춘다. 하나라도 빠지면 무시된다.
- 심각도 CRITICAL(막음) · HIGH(고친 뒤) · MEDIUM(부채 등록 가능) · LOW(반려 가능).
- negative knowledge 표에 적힌 것은 **지적하지 않는다**. 표가 비면 같은 지적이 반복된다.
- 에이전트 리뷰는 최대 7개, 발견이 없으면 "없음"만 쓴다.
