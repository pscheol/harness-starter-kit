# 기술 부채 추적기

미뤄둔 일은 시간이 지날수록 갚기 비싸진다. 쌓이기 전에 조금씩 정리한다.
부채를 발견하면 바로 여기에 등록하고, 해결하면 PR 링크와 함께 닫는다.

| ID | 항목 | 위치 | 심각도 | 상태 | 비고 |
|---|---|---|---|---|---|
| TD-000 | (예시) 초기 스캐폴딩 미비 | - | low | open | 하네스 구축 단계 |

심각도: low / medium / high. 상태: open / in-progress / mitigated / closed.

> 작성 규칙
> - 발견하면 바로 등록한다. 등록되지 않은 부채는 아무도 모르는 채로 쌓인다.
> - 해결하면 상태를 `closed`로 바꾸고 무엇으로 해소했는지와 PR/커밋 링크를 비고에 남긴다.
> - 코드로 닫을 수 없는 운영성 부채는 `mitigated`로 두고 남은 책임이 무엇인지 적는다.
> - 항목은 지우지 않는다. 이력이 남아야 하므로 심각도와 상태만 갱신한다.
